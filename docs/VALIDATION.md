# v0.2 검증 기록

검증일: 2026.10.21. 아래는 구현 동작 검증이며 실제 운전자 데이터셋 성능 평가가 아닙니다.

## 로컬 환경

- Windows 11, Python 3.12.7
- MediaPipe 0.10.35, OpenCV-contrib 4.13.0.92, NumPy 2.2.6
- 선택적 학습 경로: PyTorch 2.9.1+cpu, Torchvision 0.24.1+cpu
- 얼굴 모델: 공식 Face Landmarker float16 version 1
- SHA256: `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`

## 실행한 검사

1. 단위 테스트 25개 통과: 눈 감김·회복·히스테리시스·보정 안정성·입력 누락·시간 간격·yaw/pitch·EAR 기하·회전 행렬·검은 영상 미검출·데이터 분할·unknown 평가·ROI.
2. `scripts/integration_smoke.py` 통과: 공식 MediaPipe 예제 portrait 이미지로 640×480·20FPS·120프레임 테스트 영상을 생성. 얼굴 → 검은 화면 → 얼굴 순서로 실제 모델 검출·2초 보정·unknown·복귀·영상 기록·오버레이·JSONL을 확인.
3. 위 headless 테스트에서 처리 FPS 약 93.4, 루프 p95 약 13.0ms를 관측. 정지 이미지를 반복한 짧은 입력이므로 웹캠·다양한 운전자·행동 모델 동시 실행 성능으로 일반화할 수 없음. 벤치마크 목표 달성 수치로 사용하지 않음.
4. `scripts/action_smoke.py` 통과: 무작위 이미지 12개로 1 epoch 학습·val 선택·체크포인트·test 평가 코드 실행. 생성 가중치는 live에서 거부. 실제 행동 인식 성능의 근거가 아님.
5. 모델 다운로드/해시 검증 및 pip editable 설치 성공.

## 검증하지 못한 사항

- 실행 환경에서 웹캠 0번을 열지 못했습니다. 실제 물리 카메라로 시연 절차를 수행하는 검증은 필요합니다.
- 공개 운전자 데이터의 사용 허가·다운로드·행동 전이학습·test 성능 측정은 아직 수행하지 않았습니다.
- 안경·야간·가림·다인 추적·실제 주행에서의 오경보/누락은 평가하지 않았습니다.
- 실제 시선 벡터, 임상 졸음 3상태 분류, 이벤트 수준 성능 지표는 구현되지 않았습니다.
- 얼굴 가림의 모든 경우를 확실히 검출할 수 없습니다. 모델이 얼굴을 유효하다고 반환하더라도 일부 가림에서 잘못된 특징이 나올 수 있습니다.

각 실행은 summary.json과 설정·모델 해시를 남깁니다. CI 결과는 해당 Git 커밋의 Actions에서 확인하고, 실제 사람/데이터셋 평가는 별도 실험 기록으로 추가합니다.
