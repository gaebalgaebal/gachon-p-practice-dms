# 개발 범위와 요구사항

## 우선순위

| ID | 우선순위 | 요구사항 | 완료 조건 | 초기 상태 |
| --- | --- | --- | --- | --- |
| DMS-01 | P0 | 웹캠/영상 입력·타임스탬프 | 입력 종료·카메라 실패·프레임 유실 처리 | 예정 |
| DMS-02 | P0 | 얼굴 검출·랜드마크·EAR | 좌우 눈 지표 및 검출 유효성 출력 | 인터페이스만 제공 |
| DMS-03 | P0 | 눈 감김 시간 기반 판정 | 짧은 깜박임·장시간 감김·누락 구분 | 합성 특징 기반 규칙 구현 |
| DMS-04 | P0 | 얼굴 방향 기반 전방 주시 프록시 | 정면 기준 보정, 지속시간·가림 처리 | 합성 yaw 기반 규칙 구현 |
| DMS-05 | P0 | 상태 표시·경고·로그 | 독립 상태·unknown·타임스탬프 표시 | JSONL 특징 재생 로그 구현 |
| DMS-06 | P0 | 검증·재현성 | 운전자 분리·설정·성능표·실행법 | 검사 도구·평가 계획 제공 |
| DMS-07 | P1 | 통화·음료 분류 | 확보 클래스 기준 학습/테스트·혼동행렬 | 예정 |
| DMS-08 | P2 | 취식·흡연 및 눈 방향 | 사용 가능한 라벨·허가 확보 후 결정 | 조건부 예정 |

P0 독립 시연을 먼저 완성한 뒤 P1 통합 여부를 결정합니다. 실제 시선 추정은 얼굴 방향 규칙과 구별하고, UTA-RLDD의 각성·저주의·졸음 라벨을 단순 눈 감김 임계값과 동일시하지 않습니다.

## 제안 기술 스택

| 영역 | 후보 | 선정 전 확인 |
| --- | --- | --- |
| 영상 | Python·OpenCV | Windows/Linux 카메라 연결·시간 기준 |
| 얼굴 | MediaPipe Face Landmarker·NumPy | 설치 가능 버전·모델 사용 조건·EAR 산출 |
| 행동 | PyTorch·Torchvision·MobileNetV3-Small | 라벨·전이학습·CPU 지연·버전 호환 |
| 출력 | OpenCV 오버레이·JSONL/CSV | 경고 빈도 제한·비식별 로그 |
| UI 확장 | Streamlit | 핵심 시연 이후 필요 시 결정 |

현재 패키지에는 영상/학습 라이브러리를 설치하지 않습니다. 얼굴 어댑터 구현 시 검증한 버전을 별도 환경 파일로 고정하고 Windows/Linux 설치를 확인합니다.

## 예외 처리

- 얼굴 미검출·가림·품질 부족: unknown, 이전 판단을 현재 결과로 유지하지 않음.
- 프레임 유실·긴 시간 간격: 연속 감김·미주시 누적을 초기화.
- 여러 얼굴: 주 운전자 ROI 규칙부터 정의하고 검증 전 임의 인물 결과를 사용하지 않음.
- 조도·안경·마스크·카메라 각도: 조건별 실패율과 판단 불가 비율 기록.
- 행동 모듈 미연결·낮은 신뢰도: 정상으로 간주하지 않고 unknown.
- 정면 보정: 카메라 위치를 고정하고 중립 얼굴 방향을 수집, 실패하면 보정 재요청.
