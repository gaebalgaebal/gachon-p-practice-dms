# 운전자 상태 모니터링 사용자 안내서

## 시작과 보정

1. 바탕화면의 `운전자 상태 모니터링`을 실행한다.
2. 사용할 카메라를 선택한다.
3. 카메라·모델·저장공간 점검 완료를 확인하고 `모니터링 시작`을 누른다.
4. 얼굴과 상체가 화면에 들어오도록 앉아 정면을 보고 눈을 자연스럽게 뜬다.
5. 진행률이 100%가 되면 모니터링 화면으로 자동 전환된다.

영상은 기본적으로 저장되지 않는다. 상태 이벤트와 세션 성능 요약만 사용자 로컬 폴더에 저장된다.

## 모니터링

화면은 눈 상태, 하품, 주시 방향을 각각 표시한다. 위험 상태가 일정 시간 지속될 때만 경고한다.

- `경고음 끄기`: 현재 세션의 경고음을 음소거한다.
- `재보정`: 좌석이나 카메라 위치가 바뀐 경우 다시 보정한다.
- `세션 종료`: 결과를 저장하고 요약 화면으로 이동한다.

카메라 연결이 끊기면 자동 재연결을 시도한다. 장시간 복구되지 않으면 연결과 Windows 카메라 권한을 확인한다.

## 세션 결과와 설정

결과 화면에서 운행 시간, 처리 프레임, 상태 판정 coverage, 평균 FPS, p95 지연과 종료 사유를 확인할 수 있다. `결과 폴더 선택 내보내기`로 `session.json`과 `events.csv`를 복사한다.

설정에서는 경고음, 로그 보관 기간, 결과 저장 폴더와 로그 삭제를 관리한다. 휴대폰 항목은 시험 기능이며 일반 운행 안전 판정에 포함되지 않는다.

## 개인정보

- 기본 설정은 영상과 얼굴 이미지 미저장이다.
- 결과 파일에는 상태 이벤트와 장치·성능 정보만 저장된다.
- 사용자가 내보낸 결과는 조직의 보관 규정에 따라 관리한다.
