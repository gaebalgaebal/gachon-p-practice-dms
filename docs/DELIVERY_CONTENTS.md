# 기업 PoC 전달 구성품

1. `GachonDMS-Setup-0.4.0.exe` — 사용자별 오프라인 설치 파일
2. `release-manifest.json` — 파일 크기와 SHA-256
3. 사용자 안내서
4. 설치·제거 및 배포 빌드 설명서
5. 장애 대응표와 진단 리포트 예시
6. 기능·성능 검증 결과와 알려진 제한사항
7. 제3자 구성요소 고지와 모델 배포 검토 기록

## 운영 범위

- 운영 기능: 눈 감김, 하품, 주시 이탈, 얼굴 판단 불가
- 시험 기능: 휴대폰 행동 후보
- 기본 데이터 정책: 영상 미저장, 이벤트·세션 요약 저장
- 기준 입력: 단일 RGB 웹캠, 640×480

## 전달 전 필수 확인

- 설치본과 manifest의 SHA-256 일치
- 모델 재배포 조건 확인
- Python 없는 오프라인 Windows PC에서 설치·실행
- 관리자 권한 없는 설치·제거
- 30분 안정성 시험
- 문서의 기능·제한과 실제 화면 일치
