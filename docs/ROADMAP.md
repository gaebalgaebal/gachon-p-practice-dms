# 확정 계획 기준 일정과 남은 작업

확정안의 일정입니다. 과거 주차를 실제 완료 실적으로 간주하지 않습니다.

| 주차 | 확정 기획안 일정 |
| --- | --- |
| 1~8주차 | 아이디어·선행 조사·기본 구조·데이터 준비 |
| 9주차 | 사전평가 및 1차 멘토링 예정 |
| 10~12주차 | 웹캠·랜드마크·눈 개폐·얼굴 방향·표시 구현 및 검증 |
| 13~15주차 | 행동 모델 실험·2차 멘토링·통합·고도화 |
| 16주차 | 최종 발표·시연·보고서·코드·재현 문서 |
