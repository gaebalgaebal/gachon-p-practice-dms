# 확정 계획 기준 일정과 남은 작업

확정안의 일정입니다. 과거 주차를 실제 완료 실적으로 간주하지 않습니다.

| 주차 | 확정 기획안 일정 |
| --- | --- |
| 1~8주차 | 아이디어·선행 조사·기본 구조·데이터 준비 |
| 9주차 | 사전평가 및 1차 멘토링 예정 |
| 10~12주차 | 웹캠·랜드마크·눈 개폐·얼굴 방향·표시 구현 및 검증 |
| 13~15주차 | 행동 모델 실험·2차 멘토링·통합·고도화 |
| 16주차 | 최종 발표·시연·보고서·코드·재현 문서 |

## 수동 실험 반영 고도화 순서

1. 눈이 충분히 열린 프레임에서만 홍채 특징을 주시 판정에 사용하고, 수직 홍채값은 안정성이 확인될 때까지 진단 지표로 분리합니다.
2. 얼굴 검출과 주시 상태에 히스테리시스·유예 시간을 적용해 짧은 누락과 경계값 진동으로 인한 unknown 전환을 줄입니다.
3. 실험 중 정답 구간을 남길 수 있는 단축키 또는 라벨 입력 도구를 추가하고 같은 시나리오를 반복 측정합니다.
4. 공개 데이터셋의 사용 조건을 확정한 뒤 운전자 단위로 train/validation/test를 분리하고, 통화·음료·취식·흡연 행동 모델을 전이학습합니다.
5. 프레임 분류 지표와 함께 이벤트 재현율·오경보/분·탐지 지연을 비교해 임계값과 최종 모델을 선정합니다.
