## 완료 조건

구현 완료는 코드 존재만으로 처리하지 않습니다. 실행법·검증 입력·실패 조건·테스트·결과 기록·팀원 설명 가능 여부를 확인합니다. P0가 불안정하면 행동 클래스 확대보다 핵심 기능 수정에 시간을 배정합니다.

멘토링 전 개발 현황·데모·지표·질문을 준비하고, 이후 결정 사항을 이슈로 기록합니다. 멘토링 상세 일정과 담당자는 팀에서 확정하며 비공개 메일 원문은 저장하지 않습니다.
