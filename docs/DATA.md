# 데이터 관리

## 후보와 확인 상태

아래 항목은 제공된 계획서의 후보 목록입니다. 현재 다운로드·사용 허가·접근 가능 여부는 확인되지 않았고, 데이터나 가중치는 이 저장소에 없습니다. 실제 사용 전에 공식 제공처의 최신 조건을 확인합니다.

| 후보 | 계획 용도 | 반드시 확인할 내용 |
| --- | --- | --- |
| UTA-RLDD | 졸음 영상·각성/저주의/졸음 | 학술 사용 허가·운전자 ID·분할·라벨 대응 |
| State Farm Distracted Driver | 정상·통화·음료 등 이미지 행동 | Kaggle 이용 조건·운전자 ID·클래스 매핑; 취식/흡연을 있다고 가정하지 않음 |
| DMD | 주시·졸음·주의 분산 보완 | 공개 범위·신청 절차·학술 이용·재배포 조건 |

공식 출처는 [참고 자료](REFERENCES.md)에 모았습니다. 데이터셋별 사용 조건을 서로 대체할 수 없습니다.

```text
분할 정책 / seed / 분할 해시:
카메라·조도·도메인 차이 / 제한점:
```

## Manifest 계약

초기 검사기의 필수 CSV 컬럼은 `sample_id,subject_id,session_id,split,label`입니다. split은 train/val/test만 허용하며 모두 존재해야 합니다. subject/session은 split 간 중복을 허용하지 않습니다. session_id는 데이터셋 접두어 등을 포함한 전역 고유 값으로 생성합니다. 식별자를 확보하지 못하면 임의로 운전자 분리가 되었다고 표시하지 말고 별도 평가 방식을 협의합니다.

실제 데이터에는 원본 경로·영상 ID·프레임 시간·파일 해시 등을 로컬 manifest에 추가할 수 있습니다. 현재 검사기는 파일 내용 중복, 실제 subject ID의 정확성, 라벨 품질까지 확인하지 않습니다. 합성 manifest는 스키마 예시만 제공합니다.

## 저장·공유 원칙

- 원본은 `data/raw/`, 전처리는 `data/processed/`, 로컬 manifest는 `data/manifests/`에 보관하고 Git에서 제외.
- 얼굴 이미지·영상·개인정보·비공개 멘토링 자료·재배포 불가 가중치를 커밋하지 않음.
- 실제 촬영은 명시적 동의·목적·보관 기간·접근 통제·삭제 절차를 마련한 뒤 진행.
- 얼굴 영상을 외부 추론 서비스로 전송하는 흐름을 기본 파이프라인에 넣지 않음.
- 원본 접근이 필요한 팀원에게만 별도 승인된 경로로 제공.
- 발표용 예시·실패 사례에도 동일한 사용 조건을 적용.
