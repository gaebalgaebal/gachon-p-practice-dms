# AI Hub 이상행동 YOLO11 기준선

## 데이터 변환

- 운전 중 휴대폰 조작, 통화, 차량 제어 장면에서 장면별 중앙 프레임을 선택했다.
- 총 44,564장: train 21,111장, validation 9,674장, test 13,779장이다.
- phone_use 13,503개, phone_call 17,891개, 정상 음성 샘플 13,170개다.
- 원본에 운전자 ID가 없어 video_id를 분할 proxy로 사용했으며 proxy ID의 split 중복은 없다.
- 유효하지 않은 박스 1개와 원천 이미지가 없는 라벨 507개는 제외하고 수량을 기록했다.

중요한 한계는 박스가 휴대폰 물체 자체가 아니라 운전자 몸/행동 영역이라는 점이다. 따라서 이 모델은 휴대폰 물체 검출기가 아니라 휴대폰 사용·통화 행동 영역 검출기다.

## 학습 설정

- YOLO11n ImageNet 계열 사전학습 체크포인트
- 입력 640, batch 32, seed 42, RTX 5080, AMP
- 최대 30 epoch, patience 10; 18 epoch에서 조기 종료
- validation mAP50-95 최고 epoch 8: 45.35%
- 최고 validation 체크포인트를 고른 뒤 test를 한 번 평가

## 고정 test 결과

| 항목 | Precision | Recall | mAP50 | mAP50-95 |
|---|---:|---:|---:|---:|
| 전체 | 30.90% | 88.40% | 40.80% | 29.51% |
| phone_use | 26.50% | 88.00% | 32.10% | 23.50% |
| phone_call | 35.40% | 88.90% | 49.50% | 35.60% |

Recall은 높지만 precision이 낮다. 실시간 통합 시 단일 프레임 결과를 즉시 경고로 쓰지 않고 confidence 임계값, 연속 프레임 확인, 시간 투표를 validation에서 결정해야 한다. 또한 실제 운전자 ID 분리가 아니므로 실제 사람 일반화 성능으로 과대 해석하지 않는다.

## 정지 프레임 confidence 후보

Test를 다시 사용하지 않고 validation 정지 프레임에서 0.25~0.75를 비교했다. Recall 60% 이상 후보 중 F1이 가장 높은 0.25는 precision 46.31%, recall 74.16%, F1 57.01%였다. 그러나 후속 5프레임 장면 검증에서 정상 차량제어 200클립 모두 한 번 이상 오경보가 발생했다. 따라서 0.25는 운영 확정값이 아니라 재학습 전 비교 기준으로만 유지한다.

## 짧은 시퀀스 검증

Validation의 차량제어·휴대폰조작·통화 각 200장면, 총 600장면·3,000프레임으로 confidence와 시간 투표를 함께 탐색했다. 사전 기준인 recall 60% 이상과 정상 클립 오경보율 20% 이하를 동시에 만족한 조합은 없었다. 오경보 제약만 만족한 후보 중 최고 F1은 confidence 0.75, 3프레임 창, 최소 2표 설정으로 precision 80.61%, recall 19.75%, F1 31.73%, 정상 클립 오경보율 9.5%였다. 현재 모델은 운영 기준 미달이며 정상 프레임 강화 재학습이 필요하다.

## 균형 데이터 v2 실험

성능 개선 실험으로 차량제어 장면은 5프레임을 모두 사용하고 휴대폰조작·통화는 단일 `phone_action` 클래스로 합쳤다. 데이터는 97,244장(정상 65,850, phone 31,394), train 43,643장으로 확대됐다. YOLO11n은 9 epoch에서 조기 종료됐으며 test mAP50-95 20.50%로 v1의 29.51%보다 낮았다.

동일한 600클립 평가에서도 사전 기준을 만족하지 못했다. 최고 F1 조합의 정상 오경보율은 99.5%였고, 오경보 20% 이하 후보 중 최고 F1은 28.63%, recall 17.75%, 오경보 12.5%였다. 단순 정상 프레임 증량과 클래스 통합은 개선 효과가 없어 v2를 운영 모델로 승격하지 않는다. 다음 개선은 몸 전체 행동 박스의 구조적 한계를 고려해 State Farm 분류기 결합 또는 휴대폰 물체 라벨 데이터 도입을 검토한다.

## State Farm 분류기 교차 확인 실험

v1 YOLO 검출과 State Farm MobileNetV3의 phone 확률이 동시에 임계값을 넘을 때만 후보로 인정하는 AND 앙상블을 같은 600클립에서 평가했다. 사전 기준을 만족한 조합은 없었다. 오경보 20% 이하 최고 조합은 YOLO 0.65, MobileNet 0.50, 3프레임/3표로 precision 65.52%, recall 19.00%, F1 29.46%였다. YOLO 단독 안전 후보 F1 31.73%보다 낮아 앙상블을 운영 경로에 반영하지 않는다. State Farm과 AI Hub의 촬영 도메인 차이가 큰 것으로 해석한다.

재현 스크립트는 `scripts/train_aihub_abnormal_yolo.py`, 지표는 `models/aihub_abnormal_yolo11n.metrics.json`에 저장된다. 학습 산출물과 모델은 Git에서 제외한다.

이 프로젝트는 `opencv-contrib-python`을 사용한다. Ultralytics를 설치할 때 일반 `opencv-python`을 함께 설치하면 같은 `cv2` 파일이 충돌할 수 있으므로, 현재 환경은 Ultralytics 8.4.198과 필요한 의존성만 설치하고 기존 contrib 배포판을 유지했다.
