# 640×480 실제 웹캠 통합 성능

## 조건

- Linux `/dev/video0`, 요청 해상도 640×480·30 FPS
- MediaPipe Face Landmarker, OpenVINO eye 모델, YOLO11n 런타임 연결
- YOLO 실행 주기 5프레임, confidence 0.75
- 장치별 수동 노출 120, 최신 프레임 비동기 캡처
- 300프레임, headless, 녹화·이미지 저장 없음

## 결과

| 지표 | 결과 |
|---|---:|
| 초기 구간 포함 전체 처리 FPS | 14.33 |
| 최초 30프레임 제외 정상상태 FPS | 15.008 |
| 전체 평균 루프 | 69.79 ms |
| 전체 p95 루프 | 80.84 ms |
| 정상상태 평균 루프 | 66.66 ms |
| 정상상태 p95 루프 | 80.83 ms |
| 비동기 캡처 중 건너뛴 프레임 | 11 |

자동 노출 상태에서는 약 14.3 FPS였으며 카메라 읽기와 추론을 직렬 처리해도 같은 수준이었다. 수동 노출과 최신 프레임 캡처를 적용한 뒤 정상상태 목표 15 FPS를 근소하게 충족했다.

촬영 구간에는 유효한 얼굴이 없어 보정과 OpenVINO 눈 출력이 활성화되지 않았고 unknown coverage가 100%였다. 따라서 이 결과는 카메라·MediaPipe·YOLO가 연결된 런타임 처리량 검증이며, 운전자가 정면에 있는 세 모델 활성 시나리오는 별도로 다시 측정해야 한다. 수동 노출 120은 이 시험 장치 전용 값이다.

## 얼굴 활성 재측정

2026-11-10에 동일 장치와 설정으로 운전자가 정면에 있는 상태를 300프레임 재측정했다. 영상과 이미지는 저장하지 않았으며 수치 로그만 `runs/webcam_face_active_20261110`에 저장했다.

| 지표 | 결과 |

얼굴 활성 실제 웹캠 조건에서도 세 모델이 모두 동작했고 정상상태 15 FPS 목표를 통과했다. 300프레임 중 상태는 졸음 정상 238프레임, 정면 주시 258프레임, 하품 정상 263프레임, 행동 정상 290프레임이었다. 짧은 보정 전 구간과 시간 투표 초기 구간은 `unknown`으로 유지되어 안전한 초기화 동작도 확인했다.
