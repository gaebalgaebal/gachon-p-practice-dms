# 제품 장애 대응표

| 화면 메시지 | 원인 | 대응 |
|---|---|---|
| 사용 가능한 카메라를 찾지 못했습니다 | 미연결, 다른 프로그램 점유, 권한 거부 | 연결 확인, 다른 카메라 프로그램 종료, Windows 카메라 권한 허용 |
| 필수 모델이 없거나 손상되었습니다 | 모델 누락 또는 SHA-256 불일치 | 승인된 설치본으로 복구 설치 |
| 저장공간이 1GB 미만입니다 | 결과 경로의 여유 공간 부족 | 오래된 로그 삭제 또는 저장 위치 변경 |
| 카메라 재연결 중 | 실행 중 분리 또는 장치 오류 | 케이블 연결 확인, 복구되지 않으면 세션 재시작 |
| 카메라에 얼굴이 보이도록 위치를 조정하세요 | 얼굴 미검출 | 조명과 카메라 각도 조정 |
| 한 사람만 카메라에 보이게 해주세요 | 복수 얼굴 검출 | 운전자 외 사람이 화면에서 벗어나게 조정 |
| 카메라에 조금 더 가까이 앉아주세요 | 얼굴 영역이 너무 작음 | 카메라 거리 조정 |

시작 화면의 `진단 리포트`는 운영체제, 카메라 인덱스, 모델 체크섬, 저장공간, 최근 오류와 성능 요약을 JSON으로 저장한다. 영상이나 얼굴 이미지는 포함하지 않는다.

장애 전달 시 설치본 버전, 진단 리포트와 재현 순서를 제공한다. 얼굴 영상은 별도 동의와 보관 규정이 없는 한 전달하지 않는다.
