# YawDD 하품 구간 라벨링 설명서

이 폴더는 담당자 한 명이 Windows에서 독립적으로 작업할 수 있도록 구성되어 있습니다. 폴더 안의 영상이나 `assignment.csv` 이름을 변경하지 마세요.

## 1. 최초 설치

1. 폴더 전체를 Windows PC의 로컬 디스크에 복사합니다.
2. Python이 없다면 <https://www.python.org/downloads/>에서 Python 3을 설치합니다.
3. Python 설치 화면에서 **Add python.exe to PATH**를 선택합니다.
4. `setup_windows.bat`을 더블 클릭합니다.
5. `PASS: ... assigned videos are present`가 나오면 준비 완료입니다.

회사·학교 네트워크에서 패키지 설치가 차단되면 표시된 오류 화면을 담당자에게 전달하세요.

## 2. 라벨링 시작

`run_labeler.bat`을 더블 클릭합니다. 완료하지 않은 영상부터 자동으로 이어집니다.

| 키 | 기능 |
| --- | --- |
| `Space` | 재생 / 일시정지 |
| `[` | 하품 시작 시점 지정 |
| `]` | 하품 종료 시점 및 구간 저장 |
| `A` / `D` | 1초 뒤로 / 앞으로 이동 |
| `U` | 현재 영상에서 마지막으로 저장한 하품 구간 취소 |
| `C` | 현재 영상 검수 완료 후 다음 영상으로 이동 |
| `N` | 하품이 없는 영상으로 완료 처리 |
| `Q` | 진행 상황을 저장하고 종료 |

키 입력이 되지 않으면 한/영 키를 눌러 영문 입력 상태로 바꾸세요.

## 3. 동일한 라벨 기준

- 하품 시작: 하품을 위해 입이 지속적으로 벌어지기 시작하는 첫 시점
- 하품 종료: 입이 닫히거나 평상 표정으로 회복된 시점
- 말하기, 노래하기, 웃기는 하품으로 표시하지 않습니다.
- 말하는 중 실제 하품이 나오면 하품 구간만 표시합니다.
- 손으로 입을 가려도 턱과 입 움직임으로 하품이 명확하면 표시합니다.
- 한 영상에 하품이 여러 번 있으면 모든 구간을 저장합니다.
- 하품을 하나 이상 저장한 뒤 마지막 하품까지 확인했으면 `C`를 누릅니다.
- 하품이 전혀 없으면 `N`을 누릅니다.
- 애매한 영상은 억지로 완료하지 말고 `Q`로 종료한 뒤 영상 ID와 시간을 담당자에게 알립니다.

## 4. 실수했을 때

- `[` 시작점을 잘못 누르면 올바른 시작점에서 `[`를 다시 누릅니다.
- `]`로 잘못 저장했다면 같은 영상에서 `U`를 누릅니다.
- 이미 `C` 또는 `N`으로 넘어간 영상을 수정해야 한다면 담당자에게 알립니다. 결과 CSV를 직접 편집하지 마세요.

## 5. 제출할 파일

모든 작업이 끝나면 폴더 안에 `results` 폴더가 생성됩니다. **results 폴더 전체**를 담당자에게 전달하세요.

```text
results/
├── yawdd_MEMBER_intervals.csv
└── yawdd_MEMBER_review.csv
```

- `intervals.csv`: 실제 하품 시작·종료 구간
- `review.csv`: 하품이 없는 영상까지 포함한 전체 검수 완료 기록

원본 영상은 다시 제출하지 마세요. 데이터셋 영상을 공개 저장소나 공개 링크에 업로드하면 안 됩니다.
